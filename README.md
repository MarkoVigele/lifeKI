# lifeKI

Particle-Life im Browser. Jedes Licht trägt ein kleines Netz.

**Live:** https://markovigele.github.io/lifeKI/

![lifeKI](docs/lichtung.png)

## Start

```bash
npm install
npm run starten
```

Dann http://127.0.0.1:45221 — auf dem Mac: siehe docs/mac.md.

Oder einfach den Live-Link öffnen, ohne Installation.

## In der Anwendung

Ein Klick auf ein Licht öffnet seinen Geist. Ziehen mit der Maus wirkt als Werkzeug auf die Welt.

| Taste | Wirkung |
| --- | --- |
| `Leertaste` | Pause |
| `D` | Dock ein- oder ausblenden |
| `T` | Anleitung |
| `F` | Schönheits-Modus |
