# lifeKI

Particle-Life im Browser. Jedes Licht trägt ein kleines Netz.

**Live:** [https://markovigele.github.io/lifeKI/](https://markovigele.github.io/lifeKI/)

![lifeKI](docs/lichtung.png)

## Lokal

```bash
npm install
npm run starten
```

Dann [http://127.0.0.1:45221](http://127.0.0.1:45221). Mac-Shortcuts und Versionen: [docs/mac.md](docs/mac.md).

## Im Browser

Klick auf ein Licht öffnet den Geist. `Leertaste` Pause · `D` Dock · `T` Anleitung · `F` Schönheits-Modus.

Der Kern läuft in Rust → WebAssembly. Wir zeichnen auf einem Canvas.
